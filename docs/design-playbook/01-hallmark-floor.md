# Hallmark 的 16 条「地板规则」

来源：https://github.com/Nutlope/hallmark/blob/main/skills/hallmark/SKILL.md
作者：Nutlope（Hassan El Mghari，Together AI）。v2.0.0。

Hallmark 的说法很直接：这 16 条是**地板**，不是建议。
「无论什么场景都成立，不可豁免」。它的定位就是「挡住模型被训练出来的那套默认长相」。

下面是逐条翻译 + **对照我们站现在的情况**。
判定只有三种：✅ 已符合 / ❌ 现在违反 / ⚠️ 部分符合。

---

## 1. 颜色和字体必须走 `:root` 里声明的令牌

不能出现裸色值、裸 `font-family`。

- **我们**：⚠️ 部分符合。`packages/design-tokens/theme.css` 有令牌，但页面里仍散落大量裸值：
  `#e3eaf2`、`#f8fbfe`、`#9db4cc`、`rgba(10,37,64,0.45)` 这类直接写死在组件里。
- **为什么重要**：裸值多了，颜色就没有「一套」，看起来是几个人拼出来的。

## 2. 禁止 `transition: all`；禁止动画 width / height / top / left

- **我们**：✅ 符合。现有过渡都写了具体属性，动画走 transform / opacity。

## 3. 禁止在一个正体标题里插一个斜体词

- **我们**：✅ 符合（中文站基本不涉及）。

## 4. `html` 和 `body` 都要 `overflow-x: clip`，不能用 `hidden`，不能用 `100vw`

- **我们**：❌ 未做。首屏有 `overflow-hidden` 的 section，但没有在根上防横向溢出。
- **后果**：某个元素宽出一两个像素，整页就能横向拖动，手机上尤其明显。

## 5. 含图的自适应网格用 `minmax(0, 1fr)`；标题要 `overflow-wrap: break-word; min-width: 0`

- **我们**：⚠️ 部分符合。用了不少 `minmax(0, …)`，但不统一。

## 6. 每个可交互元素都要有 `:focus-visible`，且**立即**出现（不能有延迟）

- **我们**：❌ 基本没有。全站按钮、链接都没写聚焦样式。
- **后果**：键盘用户完全看不见自己在哪，这是无障碍硬伤。

## 7. 每个动画都要有 `prefers-reduced-motion: reduce` 降级；关掉 JS 内容也要可见

- **我们**：⚠️ 部分。`Reveal` / `HeroHeadline` 处理了 reduced-motion，但首屏的 motion 动画、轮播没有统一兜底。

## 8. 绝不编造数字、证言、logo 墙、案例数量

- **我们**：✅ 符合。`PriceCards` 里专门写了「不编折扣、不画假原价」，模型数与厂商数都从真实目录算。

## 9. 禁止 eyebrow（标题上方那行小标）；禁止大写字母加宽字距的标签

> 标签、说明、表头、tag、导航链接一律用正文字体，小一号，句首大写或全小写，**不加字距**。

- **我们**：❌ **全线违反**。这是命中最多的一条：
  - 首屏 `UNIFIED API GATEWAY`（等宽 + `tracking-[0.16em]` + 大写）
  - 每段标题上方的「平台能力」「接入示例」「接入流程」「帮助」小标
  - 卡片角上 `01`–`06` 的等宽序号
- **Hallmark 的判断**：这种「小标 + 大标题」的组合是 AI 生成页面的第一特征。
  不是不能有标签，而是不能做成「大写、宽字距、飘在标题上方」的样子。

## 10. 禁止中点连接的元信息串；禁止把箭头粘在链接文字上；禁止装饰性状态圆点

> 例：`性能 · 安全 · 可扩展`；`开始使用 →`；标题前一个小圆点。

- **我们**：❌ **全线违反**。
  - 按钮：`开始使用 →`、`打开接入文档 →`、`查看全部问题 →`（箭头是文字节点）
  - 元信息：`DeepSeek · 1M 上下文`、`对话 · 推理`、`上游模型 · 调用端`
  - 装饰点：`pv-eyebrow::before` 那个 5px 圆点
- **怎么改**：箭头做成独立图标并留出间距；元信息用换行或分隔线；小圆点删掉。

## 11. 禁止紫到蓝的渐变；禁止卡片里套卡片；禁止用 emoji 当图标；禁止手绘风格的浏览器窗口

- **我们**：⚠️ 部分违反。
  - 紫蓝渐变：**11-12 那版首屏主按钮就是 `--gradient-primary`（靛蓝→紫）**，已经被删了。✅
  - 卡片套卡片：❌ 有。`平台能力` 六张卡里，图标外面还有一层带边框的方框；
    `价格卡` 里的价格区又是一层带边框的块。
  - 手绘窗口：✅ 没有（代码窗是真实 UI 感，不是画的）。
  - emoji 当图标：✅ 没有。

## 12. 首屏的标题、一句话说明、主按钮，在 1280×800 下必须不滚动就能看全

- **我们**：✅ 符合（首屏 716 高，1280×800 下能看到按钮）。

## 13. 任何一屏大约 80 个词；首屏的文字就是「标题 + 一句话 + 按钮」

- **我们**：⚠️ 首屏符合。但下面几段一屏塞了六张卡，字数明显超标。
- **注意**：这是英文 80 词的口径，中文大约 120–150 字。

## 14. 容器要封顶并居中：1920 宽度下变宽的是**留白**，不是内容和网格

- **我们**：✅ 符合。`max-width: 1200px` + `margin-inline: auto`。

## 15. CSS 文件第一行必须是「戳记」（版本、方向、材料）

- **我们**：❌ 未做。这条是 Hallmark 自己的追溯机制，我们可用可不用。

## 16. 交付前跑一遍 `sloplint` 自动检查

- **我们**：没有这个工具。等价做法见 `02-site-checks.md` 的自查流程。
