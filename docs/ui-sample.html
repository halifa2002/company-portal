1布局：标题区没有主次，一段说明和「新建密钥」并排挤在一行，读者得先读完 40 个字才知道能点哪儿。
2信息：实际是 10 列。「分组 / 模型 / 创建时间 / 最后使用」四列在 1280 宽以下被隐藏，而 4.2 C 明确要求「创建时间」和「最后使用时间」可见 —— 最常见的笔记本上，文档要求的两项直接消失。
3字号：表格内容 12px、表头 12px、辅助信息 11px，跟正文 13–14px 几乎没差。字小加上行高紧，扫一行要停顿。
4颜色：「查看 / 编辑」和右上主按钮同一种蓝、同一个浓度。一屏五个同等重量的蓝，等于没有重点。
