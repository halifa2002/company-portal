## 0. 一页结论

现在这版预览页（v7）的问题是**它在证明自己的审美，而不是在证明平台能干什么**。轮换大标题、色带、网点、跑马灯、逐字入场，全是"作品语言"；领导看的是"这平台卖什么"。

v8 的做法反过来：**把首屏变成一个可以上手的东西**——协议切换器 + 端点 + 模型数 + 价格，四样都能点、能复制、能核对。参考 teamorouter 的首屏交互（协议 tab + BASE URL）、ohmygpt 的数据口径（按模态给计数）、aihubmix 的代码 diff、fireworks 的排版克制。**不参考** fireworks / groq / together 的叙事长卷——我们没有故事可讲，只有网关。

一句话目标：**领导打开这一页，8 秒内能说出「这是给公司用的 AI 网关，三种协议一个地址，现在接了 N 个模型，单价 X 起」。**

### 2.2 两类，别混着抄

- **叙事型**（fireworks / together / groq）：卖的是资本故事和技术信仰。首屏是宣言，往下是叙事长卷。**前提是你有资格讲故事**（自研芯片、千卡集群、融资新闻）。
- **工具型**（teamorouter / ohmygpt / aihubmix）：卖的是「现在就能用」。首屏就是**可复制的东西**：地址、协议、模型数、价格。

虫洞 AI 的条件：2 个模型、3 种协议、1 套自己写的控制台、无自研、无算力。**只能走工具型。** 走叙事型会立刻露怯——我们的 H1 撑不住"Intelligence is power"这种重量。

### 2.3 每家借一点、不借一点

| 站点 | 借 | 不借 |
|---|---|---|
| teamorouter | **首屏协议 tab + BASE URL 可复制**（这是全网最贴合我们的交互）；H1 直接写受众 | 轮换大标题（截图风险）；"Claude Code / Codex" 这种绑定单一工具的说法 |
| ohmygpt | 计数带（按类型给数字）；新上架带日期 | 294 个模型的墙（我们只有 2 个，铺开很空） |
| aihubmix | **4 行代码 diff**，改动行高亮 | 730+ 这种超大数字（我们写不出） |
| fireworks | 排版克制：大标题只占两行、正文 ≤560px、按钮只有两个 | 轮换词动画；双产品线的复杂度 |
| together | 公告条（如果我们真有上新） | 五点轮播（没有内容支撑） |
| groq | — | 整页叙事长卷、无 H1 的写法 |

## 3. 三条设计判断（我的取舍，理由写在这儿，别回头再争）

**D1｜不写大标语，写"它是什么 + 数字"。**
现在的「专用于生产环境的统一大模型网关」是对的语法、错的落点——它描述了一个品类，没有说清"给谁、几样东西、多少钱"。改成一个带数字的断言：**「一个地址，三种协议，一份账单」**。数字不是为了好看，是为了让领导能当场核对（团队真实情况：3 协议、1 地址、1 账单，全部成立）。

**D2｜彻底不用这四样：轮换标题、跑马灯、网点色带、逐字入场。**
理由不是"不好看"，是三条硬的：
1. 领导评审常截图/看一眼，轮换内容会漏掉一半信息（现在 `HOLD = 12000`，第 12 秒才换第二句）。
2. C-V-10 要求控制台避免装饰性元素，官网虽未明说，但 7.1 九条全是减法。
3. 这四样都是"设计者在说话"，会稀释"平台能干什么"。

**D3｜首屏必须有能上手的东西。**
团队最独特的资产不是文案，是"三种协议共用一套地址"。所以首屏核心控件是**协议切换器**：点 OpenAI / Responses / Claude / Gemini，右边代码区和端点路径同步变。这一件事同时满足：讲清服务（C-D-01 内容层）、证明能力（C-D-03 真实接入）、给人可复制的东西（转化）。

## 4. 信息架构：9 屏，逐屏写清

| 屏 | 名称 | 目的 | 内容 | 数据来源 | 关键交互 |
|---|---|---|---|---|---|
| S1 | 首屏 | 8 秒说清"是什么、多少、去哪" | H1「一个地址，三种协议，一份账单」+ 副标一句 + 三数字带 + 协议切换器 + 端点条 + 双 CTA | 数字来自 `loadModelList`；协议表 `lib/protocols.ts`（新建常量） | tab 切换、复制端点 |
| S2 | 一个地址 | 证明"三种协议真的同一个域名" | 4 行表：协议 / 路径 / 鉴权方式 / 对应 SDK 写法 | 同上常量 | 每行可复制 |
| S3 | 请求怎么走 | 解释网关价值，不喊口号 | 四段路径：你的应用 → 鉴权与路由 → 上游厂商 → 回你的应用；三个状态小标（200 / 429 自动重试 / 上游异常切换） | 静态 | hover 高亮当前段 |
| S4 | 你能拿到什么 | 把"网关"具象成四件日常事 | 四卡：每 Key 独立额度 / 用量明细到请求 / 账单与后台一致 / 多路重试 | 静态 + 控制台截图占位（暂用线条框，不放假 UI） | 无（可 hover 抬升 1 档） |
| S5 | 模型与价格 | 让领导能当场核对价格 | 表：模型 / 厂商 / 上下文 / 输入价 / 输出价 / 复制 model id | **`loadModelList()` 真数据**；`pricingAvailable=false` 时整表换成"价格未接通"态 | 复制 model id、行 hover |
| S6 | 三步接入 | 把接入成本压到最低 | 4 行代码 diff（只改 base_url 与 key）+ 三步说明 | 静态 | 一键复制代码 |
| S7 | 为什么是这个价 | 回答"凭什么信你" | 3 行口径表：上游采购价 → 平台一层加价 → 你看到的单价；脚注"以价格页为准，本页不构成报价" | 静态（口径文字） | 无 |
| S8 | 常见问题 | 消解最后的犹豫 | 5 条，复用已验证口径（不另写一套） | 静态（与 `/docs/faq` 同源文字） | 折叠展开 |
| S9 | 尾 | 收口 | 双入口（注册 / 看文档）+ 页脚（真实信息位，未定项留空不写"待定"） | `lib/brand` | 无 |

**屏间节奏**：浅 → 浅 → 浅（带一条细线分隔）→ 浅 → 浅（表）→ **深（代码唯一深色区）** → 浅 → 浅 → 浅。全页只有一个深色区，就在 S6，用来"换气"。

## 5. 视觉系统

### 5.1 颜色（单一强调色）

| 用途 | token | 值 |
|---|---|---|
| 底 | `--neutral-bg` | `#ffffff` |
| 浅底区 | `--neutral-bg-subtle` | `#f4fafe` |
| 正文 | `--neutral-text` | `#06223f` |
| 次正文 | `--neutral-text-mid` | `#45647a` |
| 弱文字 | `--neutral-text-muted` | `#688091` |
| 强调（唯一） | `--brand-500` / `--brand-700` | `#188df9` / `#0a74e0` |
| 强调浅底 | `--brand-50` / `--brand-100` | `#eff8ff` / `#e3f3ff` |
| 边框 | `--neutral-border` | `#dce8f0` |
| 深色区 | `--code-surface` | `#0a1929` |

> 橙色、荧光绿一律不出现在 v8 里。现有 `--accent-warm` / `--accent-lime` 不引用、不删除（删除属于全局清理，另开任务，避免影响原版首页）。

### 5.2 字号序列（5 档，不再多）

| 档 | 桌面 | 390 宽 | 用途 |
|---|---|---|---|
| display | `clamp(40px, 5.2vw, 72px)` / 1.08 | 34px | 仅 H1 |
| h2 | `clamp(26px, 2.6vw, 40px)` / 1.2 | 24px | 屏标题 |
| h3 | 20px / 1.4 | 18px | 卡片标题 |
| body | 16px / 1.7 | 15px | 正文 |
| meta | 13px / 1.4，字距 +0.08em | 12px | 标签、脚注 |

字重只用 3 档：400 / 500 / 700。

### 5.3 间距与栅格

- 8pt 栅格；屏内上下 padding：桌面 96/120，移动 56/64。
- 内容最大宽 **1280**，正文段 ≤ 620px（可读性）。
- 卡片间距 24，栅格 gap 24/32。

### 5.4 圆角与边框

- 圆角只有两档：`8px`（控件）/ `12px`（卡片）。**不出现 24px 大圆角、不出现全圆胶囊按钮**（现在是胶囊，v8 改直角 + 8px）。
- 边框 1px `--neutral-border`；阴影最多一层、不超过 `0 8px 24px -12px`。

### 5.5 动效（只留一种）

- 唯一动效：进入视口时 `opacity 0→1` + `translateY 8px→0`，**180–240ms**，`cubic-bezier(.22,1,.36,1)`。
- 禁止：逐字动画、无限循环、轮换内容、滚动视差、hover 位移超过 2px。
- 尊重 `prefers-reduced-motion`：全部取消。
- 首屏 H1 不做入场动画（避免 LCP 抖动）。

### 6.2 数据

- **模型与价格**：`loadModelList()`（已有，`lib/pricing.ts`）。返回 `pricingAvailable`，false 时 S5 整表降级为"价格未接通"说明 —— **绝不显示假数字**（C-D-04）。
- **模型数**：`models.length` 动态渲染，不写字符串常量（C-D-05）。
- **协议表**：`tokens.ts` 单一常量，S1/S2/S6 三处共用，禁止各写一份。
- **品牌信息**：`lib/brand`；未定项渲染为空字符串或省略整行，**不出现"待定"**（C-D-06）。

### 6.3 性能预算

| 指标 | 预算 |
|---|---|
| 首屏 JS（gzip） | < 120 KB |
| LCP（1440/4G） | < 1.8 s |
| CLS | < 0.05 |
| 首屏图片 | ≤ 1 张，`loading="lazy"` 之外的首屏图必须带宽高，防抖动 |
| 字体 | 只用系统栈 + 已有 `font-display`，不新引 webfont |

### 6.4 可访问性

- 正文对比度 ≥ 4.5:1（次文字 `#45647a` 对白底 ≈ 7:1，达标）
- 所有可点元素有 `:focus-visible` 描边（2px brand）
- 协议 tab 用 `role="tablist"` + 方向键切换
- 复制按钮点击后 `aria-live` 播报"已复制"
- 代码块可键盘选中（不阻止选择）

| 断点 | 主要调整 |

## 11. 需要你拍板的 4 件事

1. **H1 选哪句**：
   - A（推荐）`一个地址，三种协议，一份账单`
   - B `公司的 AI 网关：接入、计费、用量收在一处`
